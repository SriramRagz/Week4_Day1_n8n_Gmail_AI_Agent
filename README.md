# Unread Email Summariser

## Week 4 - Day 1 Assignment

Build an n8n AI Agent for Gmail.

## Objective

Build an AI Agent workflow in n8n that connects to Gmail, fetches the latest 5 unread emails, generates a one-line summary for each email, combines the summaries, and emails them back to the user.

## Workflow Components

1. Manual Trigger
2. Gmail - Get Many
3. AI Agent with Chat Model
4. Aggregate
5. Gmail - Send

## Requirements

- Fetch 5 unread emails using Gmail.
- Generate one summary line per email.
- Each summary must contain a maximum of 20 words.
- Combine all five summaries into one message.
- Send the consolidated message to your own Gmail address.
